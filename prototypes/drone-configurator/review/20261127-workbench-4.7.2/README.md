## 三、从这一夜得到的两条写法

1. **文字管不住的，交给条件图。** 布局本来就是条件图管的；旋翼只靠文字，换多少种写法都只是换一种错法，画进条件图就稳了。
2. **不要在句子里提不想要的东西。** “not a folding propeller”“no lens glass is visible”这类否定句，真机上反而把折叠桨、镜片叫了出来。改成正面描述顶视里看得见的是什么。

工作台的自检（`npm run verify`）不许模板句自带颜色词：机鼻下挂那一句从 v1.6 搬回来时带着 “dark grey”，被它拦下，去掉了。
