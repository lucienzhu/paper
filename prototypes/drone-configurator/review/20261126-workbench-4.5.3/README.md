# 工作台 4.5.3 复核记录（2026-11-26）：条件图读法那一句不再写颜色

工作台流程第一次在真实 GPU 上出图（环境核对，RTX 4090 D）。主机没有问题：同一份请求出两次，逐像素相同。但图上有条件图的颜色：机臂上有蓝色条纹，电机里发红。4.5.3 改掉了它。

## 二、依据

[条件图颜色残留的开发小批](../../../../experiments/20261126-guide-colour-dev/README.md)：同一个状态、同一组 4 个种子，比三种做法；选法和阈值在出图前写定，残留用程序量。

| 做法 | 有残留的张数 |
| --- | --- |
| 现行：文字里写“red dots…blue lines” | 3/4（重的一张蓝色占全图 2.2%） |
| 只去掉颜色词，条件图不动 | 0/4 |
| 去掉颜色词，条件图也换成中性色 | 0/4 |

颜色是文字带进去的，不是条件图带进去的。按规则选改动小的。Claude 知条件地看了选中做法的 4 张：四个电机、四根机臂、X 形布局、完整的产品，没有蓝色条纹。

## 三、改了什么

- `src/design/partPrompt.ts` 条件图读法那一句：“red dots mark motor centres, blue lines mark frame links” 改为 “dots mark motor centres, lines mark frame links”。别的一个字没动。
- 界面上给设计者看的中文说明（“红点是电机轴心，蓝线是机架连接”）不变：条件图确实还是红点蓝线。
- 版本号 4.5.2 → 4.5.3；离线包按 4.5.3 重打。
- 各批 GPU 请求从 4.5.3 重新取出。核对过：取出的 F6 基准状态的文字，与开发小批里选中做法的文字逐字相同；条件图的摘要没变。
