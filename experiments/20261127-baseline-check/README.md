# 修正后的基准：检查小批（出图前写定，Claude，2026-11-27）

**为什么做。** 两个开发小批定了两处修正：相机用 C3（作者 2026-11-27 确认），配色按部件给（机身、机臂、桨叶控得住）。还有一处是看图时发现的：起落架在顶视里露出深色的脚。三处一起写进了工作台 4.6.0 和新的基准状态。**在跑任何登记的批次之前，先看这三处合在一起是不是好的。**

**对蓝图。** 仍是冻结前的开发；这批图不进任何正式分母。它过了，F6 的确认批才用这个基准、用新种子重新登记。

| MOT | 与 BASE 只差配色那一句：在机臂和桨叶之间加 “motor housings neutral grey (#8a9095)”。再试一次电机颜色能不能控住（上一批用 “motors” 没控住） |

## 怎么看（出图前写定）

每张判这几项，Claude 知条件地逐张写下，总览图和机鼻裁图交给作者，作者的判断为准：

1. 相机内嵌：机鼻前缘只有一条窗带，没有越出机鼻的块，没有正对观察者的镜片。
2. 顶视里看不到起落架的脚或撬杆。
3. 机身和机臂是银灰，桨叶是深色（炭黑）。
4. 每个电机一副双叶桨。
5. 四个电机、四根机臂、完整的产品；没有条件图颜色残留（程序量）。
6. 只对 MOT：电机壳是不是中性灰。

**规则：** BASE 的 4 张里，第 1、2、3、5 项各至少 3 张成立，这个基准才用于确认批；哪一项不到 3 张，先改那一项，再出一小批。第 4 项单报。MOT 的电机 4 张里至少 3 张是中性灰，电机颜色这一项才留在工作台里；否则从工作台里去掉这一项。
