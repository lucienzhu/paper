## 五、读数和判据（出图前冻结）

**读数。** 同 A4 第六节，一样东西不改：两位相互独立、不知条件的 AI 读者取点；取点规则 [point-rules.txt](../20261127-a4-bridge/point-rules.txt)，工具 [point_tool.py](../reading/point_tool.py)，任务说明 [brief.md](../20261127-a4-bridge/ai-reading/brief.md) 的原文（只改张数和目录），模型固定 Opus 5.5。每位读者的 36 张分三份、一个实例做一份（每份 12 张），随机图号、各自打乱、去掉元数据；读数包在库外，目录名不透露内容；对照表在读者运行期间锁住；启动前核对最近的提交标题和 git 状态；读完逐条核对工具调用。

**每张图的命中**（照 A4，三项都成立）：

1. 这张图所属因素的读数取两位读者的均值，|均值 − 目标| 不超过容差：**W/L 0.10，d/D 0.05**（A4 的容差，不改）。
2. 两位读者都答“机臂连着”。
3. 两位读者都答“是一件产品”。

**逐档最低命中数：W/L 每档 8 张里至少 6 张；d/D 每档 4 张里至少 3 张**（都是四分之三；F6 确认批登记的也是每档 6/8）。

**一个因素记“确认”：三档都达到最低命中数。** 有一档达不到就记“没有确认”，5.2.1 照实写哪一档、差几张、读数是多少。两个因素分开判，不合并。

**缺测规则。**

- 一份请求没有出图（报错、断线对账后仍没有）：这一张记未命中，分母不变（8 或 4）。**不重试、不换种子、不补图、不挑图。**
- 一位读者把这张图所属因素要用的点留空，这一项算不出来：这一张记未命中。
- 两位读者在这张图所属因素上的读数相差超过该因素的容差：读数定不下来，这一张记未命中，并单列出来。
- 读者越界（碰了自己目录以外的东西）或启动上下文漏了内容：那一位读者的那一份作废，换一个新的实例、重新匿名后重读；作废的照实记，不拿来计分。

**全部报告。** 36 张逐张的读数（两位读者各自的和均值）、每档的命中数、中位数和范围、保持项（不是这张图所属因素的另两个比例）、两位读者之差，都进记录；没命中的不删。

**另外看、但不进门的：** 研究者知条件的整张图验收（旋翼先量，再逐项看）和程序速量，照 A4 的验收记录的做法，只并排列出，不拿来改判读者的读数。

**先写明的一处局限。** 判据第 3 项“是一件产品”由 AI 读者回答。今天第一位真人读者的回件（[回件记录](../reading/returns/20261127/README.md)）显示，同一类四旋图，真人填“是”的只有 14/52，AI 读者全填“是”。所以这一项在 A5 里只起“筛掉根本不成飞行器的图”的作用，**不能当作“这些图像产品”的证据**；这类评价要靠真人。A5 确认的是比例跟不跟得上。
