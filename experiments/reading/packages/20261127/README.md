## 发给读者的话（可以直接转发）

> 请下载发给你的压缩包，**完整解压**后双击里面的 `index.html`，用电脑上的浏览器打开（Chrome、Edge、Safari 都可以，不需要联网，图和读数都不会上传）。一张一张看图、点选；看不清的地方点图可以放大；拿不准就选“看不清”，不要硬选。进度自动存在这台电脑的浏览器里，中途可以关掉，再用同一个浏览器打开会接着做。全部填完后点右上角“导出读数”，把下载到的 `reading.csv` 发回给我。请独立完成，不要和别的读者商量，也不要去查这些图的来历。

## 要注意的

- **作者知道条件，不能自己读。**
- 这个仓库是公开的，别的目录里有带条件名的原图和 AI 读者的读数。**只把上面的下载链接发给读者，不要让读者翻仓库。**
- 读数回来以后，文件名标上是哪一包、哪位读者（例如 `A-reader3.csv`），交给 Claude 计分，或照各登记页写的命令自己跑。图号与请求号的对照表不在仓库里（在本机的库外目录），四份读数都回来以后再进仓库。
- 要找更多读者：每多一位就要另封一个匿名包（新的图号和顺序），告诉 Claude 要哪一包、几位。
