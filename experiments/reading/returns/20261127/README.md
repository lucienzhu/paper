## 三、读者 3 和作者都指出的一件事：四旋的图不像产品

- **读者 3 的读数：** 四旋的图（A 包 48 张、C 包的 4 张参照）里，填“是一件产品”的只有 14/52；植保六旋 10/10；八旋 2/4。同一位读者、同一天、同一套页面，差别在图本身。
- **A 包里分档看：** 基准、方盒机身、承座、铰链四档合起来 2/32；机鼻下挂相机 7/8；多片顶盖 5/8。也就是**机身上多一点可辨的部件或分缝的图，才被认成产品**；一整块光滑的浅灰舱体不被认。只有一位读者，这一条先当线索，不当结论。
- **作者 11-27 看图后的意见（原话的意思）：** 图都有点丑；铰链的结构不太符合实际；很多图里部件怪、造型怪、发平，小毛病多；八旋一般不拿来航拍，多是大载重机型，现在这个设计有点怪。作者同时说：如果达到了预期就接着往前推，以实际的进度和方向为准，把目标做成。
- **这和 AI 读者的关系：** AI 读者在“是不是完整的产品”上 48/48、8/8 全填“是”，真人 14/48、2/8。#3 已定“AI 判读不单独支撑正式结论”；这里是它在这套流程里的第一处实证：**类别判读（机身、臂根、相机、顶盖、轴位）真人和 AI 大体一致，“像不像产品”这种评价性的判断 AI 读者不能代替真人。**
- **对后面的影响（要作者定的写在现状总表第四节）：** A4、A5 的命中判据里有“两位读者都答是一件产品”，现在两位读者都是 AI；E 组评议、S5 第二步要给人看的图是从同一个基准状态出的。
