# F6 确认批的验收记录（Claude，知条件，不进任何分母）

按[验收标准](../../reading/acceptance-standard.md)整张图逐张看；旋翼先用 `rotors.py` 量（“直”指两片桨叶长轴相差 10° 以内），再看每副桨的裁图；机身、相机、臂根、顶盖看原分辨率裁图。确认批不换图、不挑图、不重出单张：这里只照实记。**这不是判读**：各档“出没出来”由不知条件的读者按[登记的读法](../reader-rules.txt)读。

每档一张总览（`overview-<档>.png`，按 r01—r08 从左到右、从上到下）和一张机身裁图（`bodies-<档>.png`，r01—r08 从左到右）。
