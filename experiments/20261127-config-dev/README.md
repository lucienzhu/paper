# 构型开发检查小批：植保六旋、平面八旋、共轴 X8（出图前写定，Claude，2026-11-27 02:36）

**为什么做。** 六旋、八旋、共轴 X8 的确认批（农业植保 10 张、H5 第一段 12 张）是 11-26 从工作台 4.5.3 取出的，之后流程改了四处（条件图读法不写颜色、相机负向词、分部件配色、**条件图上画桨**）。四旋上修好的东西，在别的构型上成不成立没有看过；尤其八旋的直杆首尾几乎相接，会不会被画成一圈护环，要先看。作者的规矩：每个新构型先出开发小批，过门再跑确认批。

**对蓝图。** RQ4“换一种任务、换一种构型，流程还成立吗”，5.5.1（农业植保六旋，H2、H3）、5.5.2（八旋与共轴，H5）。这批是开发图，不进任何分母；不新增研究问题、不新增测量。

## 怎么看（出图前写定）

逐张按[验收标准](../reading/acceptance-standard.md)整张图看，知条件；旋翼逐副看原分辨率（`rotors.py` 是按四旋深色桨写的，能用就用，不能用就人眼逐副数）。

- 六旋：6 个电机 6 根机臂；每个电机一副直的双叶桨；药箱和加注口在；喷洒部件是登记的那一种（横向喷杆，或六个电机下方的喷头）；没有相机。
- 八旋：8 个电机 8 根机臂，每个电机一副直的双叶桨；没有把直杆连成一圈的护环或外框；机身、相机、配色同四旋基准。
- X8：4 根机臂 4 处轴位；每处看得出上下两副桨（下层可以被遮住一部分），不是四旋；机身、相机、配色同四旋基准。

**门：** 每个状态的 2 张都整张图合格，这个构型才跑确认批（用新种子，请求从 4.7.0 重新取出、重新登记）。有不合格的，找出原因改了再出一小批。只有一种做法怎么改都出不来时，照实写“这个构型在这条流程上出不来”，交作者定。
