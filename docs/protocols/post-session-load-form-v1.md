# 场后短表 v1（草案，Claude，2026-11-26）

**状态：草案，等作者看。** 作者两场预试（C2）用这一稿，预试以后定稿并冻结。表本身是一个离线网页：[post-session-load-form-v1.html](post-session-load-form-v1.html)。

## 登记的是什么

任务表 C1 和[预试记录约定](../../evidence/20261117-research-update/method/paired-pilot.md)列的测量里有一项“主观负荷短表”，只写了这个名字，没有定量表。这一稿把它定为 **NASA-TLX 原始版**：

- 六个分量：脑力需求、体力需求、时间压力、表现、努力程度、挫败感。
- 每项 0—100，每格 5，共 21 格。
- 不做两两比较加权。

**为什么选它：**
- 文献库里做人智协同比较的几篇（如 L072）都量了负荷。[文献关系图](../../literature/map.md)第 168 行把 NASA-TLX 列为库内被引 11 次、本文会直接用到的经典。
- 原始版不做两两比较，六题约 2 分钟答完，合“短表”的意思。

## 怎样填

- 每一场结束后马上填，在两场之间的休息之前。
- 主持人先填参与者编号、场次、方式、委托四项，再交给参与者。参与者自己填，主持人不看屏幕。
- 六题都答完才能导出。导出的 JSON 和本场的工作台 ZIP 放在同一个场次文件夹里。
- 表里记下打开时间、每题第一次作答的时间和导出时间，不记别的。

## 怎样算

- **每个分量单报，另报六项的平均分（原始 TLX）。**
- “表现”一项照原量表的方向：0 是完美，100 是失败。所以六项都是数值越大负荷越重，平均时不用反向计分。
- 两种方式之间按人配对，报告每人的差值。3 名外部设计者只够描述，不做检验，与 C3 的登记一致。

## 还没做的、要作者定的

1. **中文措辞。** 现在的题目是 Claude 照 NASA-TLX 各分量的定义改写的中文，不是已发表、经过验证的中文版。用已发表的中文版，还是用这一稿，作者定。
2. **原始文献不在文献库里。** 写作前要补进文献库并核原页（Hart & Staveland, 1988；Hart, 2006），见 CLAUDE.md 的引用规则。
3. **旧问卷的另外四题不加。** 旧材料包第 3 节的场后问卷有五题：意图表达、控制感、负担、是否愿意再用、补充意见。现行登记只留了“主观负荷短表”这一项测量。另外几题要不要加回，是扩大测量范围，由作者定。这一稿不加。
